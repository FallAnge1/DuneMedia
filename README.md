# Видеоархив

Личный видеоархив «как Pinterest» для небольшой команды. Оригиналы видео лежат в публичном
Telegram-канале, сайт показывает их плиткой с превью при наведении, а по клику ведёт в пост Telegram,
где видео можно скачать. Всё работает на бесплатных тарифах Cloudflare.

| Часть | Папка | Статус |
|---|---|---|
| Бэкенд: Cloudflare Worker + D1 + R2 + Workers AI | `web/worker`, `web/migrations` | ✅ этап 1 |
| Сайт: Vite + React + TypeScript | `web/src` | ✅ этап 2 |
| Программа-загрузчик: Python + PySide6 + Telethon | `uploader/` | ✅ этапы 3–4 |
| Сборка (Windows, macOS) и инструкции | `uploader/build/`, `.github/workflows/`, `docs/` | ✅ этап 5 |

**Начать:** [docs/00-quickstart.md](docs/00-quickstart.md) — от нуля до первого видео по шагам.

**Одной кнопкой:** `setup-site.bat` / `setup-site.command` — настроить или обновить сайт на Cloudflare;
`invite.bat` / `invite.command` — установить программу себе или пригласить другого загрузчика.

## Сайт

- Плитка с реальными пропорциями видео; в DOM только видимые карточки, поэтому тысячи видео не тормозят.
- При наведении играет беззвучное превью, движение мыши перематывает его; на телефоне — первый тап.
- Мгновенный поиск (клавиша `/`) с учётом опечаток и окончаний, фильтры по тегам (логика «И»),
  ориентации, разрешению и длительности, вкладки коллекций, «Избранное» (в браузере), сортировка.
- Все фильтры и открытое видео хранятся в адресе страницы — ссылкой можно поделиться.
- Тёмная и светлая тема, размер плиток, вёрстка от 360 px до 4K.

### Редактирование на сайте

Смотреть архив можно без входа. Кнопка с ключом в шапке включает режим редактирования
по **токену загрузчика** (тому же, что в программе). В этом режиме можно:

- менять название, описание, теги и коллекции видео (кнопка «Редактировать» в окне просмотра);
- выделять несколько видео (кнопка выбора в шапке, Shift — диапазон) и массово добавлять/убирать теги и коллекции;
- создавать, переименовывать, упорядочивать и удалять коллекции; переименовывать, сливать и удалять теги;
- удалять видео с сайта (пост в Telegram остаётся).

Сайт не может менять посты в Telegram: для этого нужен Telegram-аккаунт загрузчика.
Видео, у которых на сайте поменяли название, описание или теги, помечаются, и программа-загрузчик
обновляет подписи их постов.

## Быстрый старт (разработка)

Нужны Node.js 20+ и ffmpeg (для тестовых роликов).

```bash
cd web
npm install
npm run db:migrate:local      # создать локальную базу
npm run build                 # собрать сайт
npm run dev                   # сайт и API: http://localhost:8787
npm run seed                  # в другом терминале: 50 тестовых видео + токен для входа на сайт
```

- `npm run dev:web` — сайт с горячей перезагрузкой на http://localhost:5173 (API берётся с `npm run dev`).
- `npm run dev` работает полностью локально. ИИ-эндпоинт (`/api/ai/tag`) в этом режиме недоступен,
  для него запустите `npm run dev:ai` (нужен вход: `npx wrangler login`).
- `npm test` — тесты API и логики сайта, `npm run typecheck` — проверка типов.
- Токен для локальной разработки: `npm run uploader:create -- "Я" --local`.

Описание API: [docs/api.md](docs/api.md).

## Программа-загрузчик

Установщики для Windows и macOS собираются в GitHub Actions (**Actions → «Сборка загрузчика»** или тег
`uploader-v0.1.0`) — см. [docs/06-uploader-install.md](docs/06-uploader-install.md).
Запуск из исходников и устройство — [uploader/README.md](uploader/README.md).

## Как устроено

- `GET /api/library` отдаёт весь архив одним JSON; сайт фильтрует и ищет на клиенте.
  Ответ кэшируется: `ETag` по ревизии архива и готовый снимок JSON в R2, поэтому
  D1 читает одну строку на запрос, пока архив не меняется.
- Превью (mp4) и постеры (jpg) делает загрузчик через ffmpeg и кладёт в R2 через `PUT /api/media/...`.
- Запись — только с персональным токеном загрузчика (в программе или в режиме редактирования на сайте).
