# Быстрый старт: от нуля до первого видео на сайте

Всё делается один раз и занимает около часа. Подробности по каждому шагу — в соседних инструкциях
(ссылки в конце каждого шага).

**Понадобится:**
- аккаунт Telegram (тот, от имени которого будете загружать);
- аккаунт Cloudflare — бесплатный, https://dash.cloudflare.com/sign-up;
- банковская карта или PayPal — Cloudflare просит её, чтобы включить хранилище R2. **Деньги не списываются**, пока архив меньше 10 ГБ (≈ 7–9 тысяч видео);
- аккаунт GitHub — чтобы скачать программу;
- компьютер с Windows 10/11 или macOS.

---

## Шаг 1. Канал в Telegram (5 минут)

1. В Telegram создайте **новый канал** → тип **Публичный** → придумайте ссылку латиницей, например `dune_media_archive`. Запомните её — это **username канала**.
2. В настройках канала **выключите «Запретить копирование»**, иначе видео нельзя будет скачать.
3. Если загружать будете не вы один — добавьте людей **администраторами** с правами «Публикация сообщений», «Редактирование чужих сообщений», «Удаление чужих сообщений».

Подробно: [01-telegram-channel.md](01-telegram-channel.md)

## Шаг 2. Ключи api_id и api_hash (5 минут)

1. Откройте https://my.telegram.org, введите свой номер (`+7…`). Код придёт **в приложение Telegram**.
2. **API development tools** → App title: `Video Archive`, Short name: `videoarchive`, Platform: `Desktop` → **Create application**.
3. Сохраните **api_id** (число) и **api_hash** (32 символа) — они понадобятся в шаге 5.

Подробно: [02-telegram-api.md](02-telegram-api.md)

## Шаг 3. Сайт на Cloudflare (20–30 минут)

### 3.1. Подготовка компьютера

1. Установите **Node.js** с https://nodejs.org (большая зелёная кнопка LTS, всё по умолчанию).
2. Скачайте проект: https://github.com/FallAnge1/DuneMedia → зелёная кнопка **Code → Download ZIP** → распакуйте, например, в `Документы\DuneMedia`.
3. Включите хранилище R2: панель Cloudflare → слева **R2 Object Storage** → **Purchase R2 Plan** (план Free, $0) → привяжите карту.

### 3.2. Команды

Откройте терминал **в папке `web`** проекта:
- **Windows:** откройте папку `DuneMedia\web` в Проводнике → правый клик по пустому месту → «Открыть в Терминале».
- **macOS:** Терминал → наберите `cd ` (с пробелом), перетащите папку `web` в окно, нажмите Enter.

Вводите команды по одной, дожидаясь окончания каждой:

```bash
npm install
npx wrangler login
```
Откроется браузер — нажмите **Allow**.

```bash
npx wrangler d1 create video-archive
```
Команда напечатает строку вида `database_id = "a1b2c3d4-…"`. Откройте файл **`web/wrangler.toml`** в Блокноте (или TextEdit),
найдите строку `database_id = "00000000-0000-0000-0000-000000000000"`, замените нули на ваш id и сохраните файл.

```bash
npx wrangler r2 bucket create video-archive-previews
npm run db:migrate:remote
npm run deploy
```
В конце `deploy` напечатает адрес сайта, например `https://video-archive.ваше-имя.workers.dev`.
**Откройте его** — должна появиться страница «Архив пока пуст».

```bash
npm run uploader:create -- "Ваше имя"
```
Скопируйте токен, который начинается на `va_…`. Он показывается **один раз** — сохраните его, он нужен в шаге 5.

Подробно и про свой домен: [03-cloudflare.md](03-cloudflare.md), про токены: [04-tokens.md](04-tokens.md)

## Шаг 4. Установить программу-загрузчик (5 минут)

1. Войдите на GitHub и откройте https://github.com/FallAnge1/DuneMedia/actions/workflows/uploader-release.yml
2. Нажмите на верхний запуск с зелёной галочкой → внизу страницы раздел **Artifacts** → скачайте:
   - **Windows:** `VideoArchive-win64` → в архиве `VideoArchive-Setup-….exe`;
   - **Mac на Apple M1–M4:** `VideoArchive-mac-arm64`;
   - **Mac на Intel:** `VideoArchive-mac-x64`.
3. Установите:
   - **Windows:** запустите `VideoArchive-Setup-….exe`. Если появится «Windows защитила ваш компьютер» → **Подробнее → Выполнить в любом случае**.
   - **macOS:** откройте `.dmg`, перетащите «VideoArchive» в «Программы». Первый запуск: **правый клик по программе → Открыть → Открыть**.

Подробно: [06-uploader-install.md](06-uploader-install.md)

## Шаг 5. Мастер настройки (5 минут)

При первом запуске откроется мастер:

1. **Вход в Telegram:** вставьте api_id и api_hash (шаг 2), номер телефона → **Получить код** → введите код из Telegram → **Войти**. Если включена двухэтапная проверка — введите пароль.
2. **Канал:** username канала из шага 1 → **Проверить**. Должно быть «можно публиковать».
3. **Сайт и токен:** адрес сайта и токен `va_…` из шага 3 → **Проверить связь**. Поля «Access» оставьте пустыми.
4. **ИИ-теги** — можно пропустить (**Далее**). Чтобы ИИ предлагал теги, добавьте хотя бы один бесплатный ключ — [05-ai-keys.md](05-ai-keys.md). Cloudflare Workers AI работает и без ключа.
5. **Готово** — программа покажет ваш лимит на размер файла (2 ГБ или 4 ГБ с Premium).

## Шаг 6. Первое видео (проверка, что всё работает)

1. Перетащите в окно программы **одно небольшое видео**.
2. Подождите, пока появится постер и статус «готово к загрузке».
3. Нажмите на файл в списке → справа поправьте **название**, впишите **теги** через запятую (например `закат, море, дрон`). Если настроен ИИ — нажмите **✨ Предложить теги (ИИ)** → **Применить всё**.
4. Нажмите **Загрузить всё**. Будет видно этапы, процент, скорость.
5. Проверьте:
   - в Telegram-канале появился пост с файлом и хештегами;
   - на сайте (обновите страницу) появилась плитка; при наведении мышью играет превью, клик → **Открыть в Telegram**.

Если всё так — архив работает.

## Как пользоваться каждый день

**Загружать** (программа, вкладка «Загрузка»):
- перетаскивайте файлы или целые папки; превью и проверка дубликатов делаются сразу;
- выделите несколько файлов (Ctrl или Shift) — справа можно разом добавить теги или коллекцию;
- **Загрузить всё** — дальше можно заниматься своими делами. Если пропал интернет или вы закрыли программу, при следующем запуске загрузка продолжится;
- предупреждение «⚠ дубликат» — такое видео уже есть; отметьте «Загрузить всё равно», если нужно.

**Смотреть и искать** (сайт, вход не нужен):
- `/` — поиск; слева фильтры по тегам, ориентации, разрешению, длительности; вверху — коллекции и ♡ Избранное;
- ссылку с выбранными фильтрами можно отправить коллеге — откроется то же самое;
- клик по видео → **Открыть в Telegram** → скачать оригинал.

**Править на сайте:** кнопка с ключом в шапке → вставьте свой токен `va_…`. Появятся «Редактировать» в окне видео,
кнопка выбора нескольких видео и «Коллекции и теги». Подписи постов в Telegram программа обновит сама при следующем запуске.

**Править в программе** (вкладка «Библиотека»): двойной клик по видео — правка вместе с подписью поста;
**Удалить…** — с сайта или с сайта и из Telegram; **Коллекции…**, **Теги…** (переименовать, слить два в один);
**Проверить синхронизацию** — найдёт видео, чьи посты удалили в канале вручную.

## Добавить ещё одного загрузчика

1. Сделайте человека администратором канала (шаг 1, п. 3).
2. В папке `web` выполните `npm run uploader:create -- "Его имя"` и отправьте ему токен лично.
3. Он сам делает шаги 2, 4 и 5 — **своим** Telegram-аккаунтом. Не копируйте ему свою папку программы.

## Если что-то не так

| Проблема | Что делать |
|---|---|
| «Сайт не принял токен» | Проверьте токен; если отозван — создайте новый (`npm run uploader:create`) |
| «Нет права публикации» в мастере | Вы не администратор канала или нет права «Публикация сообщений» |
| «Файл больше лимита Telegram» | Сожмите видео (например, HandBrake) или разделите на части |
| «Telegram просит подождать N с» | Ничего — программа подождёт и продолжит сама |
| ИИ: «Ни один провайдер не ответил» | Лимиты закончились или ключи неверны: Настройки → Мастер настройки → ИИ → «Проверить провайдеров» |
| `npm` не найден в терминале | Node.js не установлен или терминал открыт до установки — перезапустите терминал |
| Сайт пишет «Архив не загрузился» | Не выполнены `npm run db:migrate:remote` или `deploy` — повторите шаг 3.2 |
| Любая другая ошибка программы | Настройки → «Открыть папку с логами» → приложите `app.log` к вопросу |

Лимиты бесплатных тарифов: [07-limits.md](07-limits.md). Как закрыть сайт от посторонних: [08-cloudflare-access.md](08-cloudflare-access.md).
