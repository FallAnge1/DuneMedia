# 2. Ключи api_id и api_hash

Программа загружает видео от имени вашего аккаунта через официальный протокол Telegram (как приложения
Telegram Desktop). Для этого Telegram выдаёт пару ключей **api_id** и **api_hash**.

> Почему не бот? Боты Telegram не умеют загружать файлы больше 50 МБ, а через аккаунт можно до 2 ГБ
> (до 4 ГБ с Telegram Premium).

## Как получить

1. Откройте **https://my.telegram.org** и введите номер телефона в международном формате (`+7…`).
2. Код придёт **в приложение Telegram** (не по SMS) — введите его на сайте.
3. Нажмите **API development tools**.
4. Заполните форму:
   - **App title** — любое, например `Video Archive`;
   - **Short name** — латиницей, 5–32 символа, например `videoarchive`;
   - **Platform** — `Desktop`;
   - остальные поля можно не заполнять.
5. Нажмите **Create application**. На странице появятся:
   - **App api_id** — число, например `12345678`;
   - **App api_hash** — строка из 32 символов.
6. Скопируйте оба значения в мастер настройки программы (шаг «Вход в Telegram»).

Если сайт пишет «ERROR» при создании — попробуйте другое Short name, отключите VPN/блокировщики или
повторите через несколько часов.

## Безопасность

- api_id и api_hash сами по себе не дают доступа к аккаунту, но не публикуйте их.
- После входа программа хранит **сессию Telegram** в файле `telegram.session` в папке данных программы.
  Этот файл — как пароль: **никому его не передавайте и не копируйте на чужие компьютеры.**
- Завершить сессию можно в Telegram: **Настройки → Устройства** → «VideoArchive Uploader» → Завершить.
- Каждый загрузчик получает ключи и входит **сам**, на своём компьютере.
