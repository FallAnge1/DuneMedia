# 5. Бесплатные ключи для ИИ-тегов

ИИ смотрит 4–6 кадров из видео (не само видео — это экономит лимиты) и предлагает название, описание
и 5–12 тегов. Предложение **не применяется само**: вы видите его в программе и нажимаете «Применить».

Все провайдеры необязательны. Программа пробует их по порядку: если один упёрся в лимит, ошибся или
ответил ерундой — сразу переходит к следующему, а «уставший» провайдер пропускает до сброса лимита.
В очереди видно, какой провайдер ответил (✨ ИИ: Groq).

Ключи вводятся в мастере настройки (шаг «ИИ-теги»). Кнопка **«Проверить провайдеров»** покажет,
работает ли ключ и какие модели доступны.

| Провайдер | Где взять | Заметки |
|---|---|---|
| **Groq** | https://console.groq.com/keys → Create API Key | Очень быстрый. Лимиты бесплатного тарифа — на странице Limits в консоли |
| **OpenRouter** | https://openrouter.ai/keys → Create Key | Бесплатные модели с пометкой `:free`. Без пополнения — около 50 запросов в день, после разового пополнения на $10 — около 1000 |
| **Cloudflare Workers AI** | ключ не нужен — работает через ваш сайт | 10 000 «нейронов» в день бесплатно |
| **Google Gemini** | https://aistudio.google.com/apikey → Create API key | Лимиты — в AI Studio. На бесплатном тарифе Google может использовать данные для улучшения сервисов |
| **Ollama** | https://ollama.com — программа на ваш компьютер | Без лимитов и интернета, но нужен мощный компьютер |

> Сервисы доступны не во всех странах. Если провайдер пишет об ошибке доступа из вашего региона —
> выключите его или используйте другой. Workers AI и Ollama работают всегда.

## Модели

Бесплатные модели у провайдеров часто меняются, поэтому в программе они не «зашиты»:
- поле «модели» можно оставить **пустым** — программа сама спросит у провайдера список и выберет
  бесплатные модели, которые понимают картинки (для OpenRouter — точно по каталогу, для остальных — по названию);
- или впишите свои через запятую — они будут пробоваться по порядку.

## Ollama (по желанию)

1. Установите с https://ollama.com и запустите.
2. Скачайте модель, которая понимает картинки (в терминале):
   ```bash
   ollama pull qwen2.5vl:7b    # ~6 ГБ, лучше качество, нужно ~8 ГБ видеопамяти или ОЗУ
   ollama pull gemma3:4b       # ~3,3 ГБ, для слабых компьютеров
   ```
3. В программе включите Ollama (адрес `http://localhost:11434`).

## Если ИИ ошибается

ИИ старается использовать **уже существующие теги** архива (список передаётся ему вместе с кадрами),
а программа дополнительно сводит формы слов, синонимы и опечатки к существующим тегам:
«закаты» → «закат», «квадрокоптер» → «дрон», «вадопад» → «водопад».
