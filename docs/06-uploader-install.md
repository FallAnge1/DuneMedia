# 6. Программа-загрузчик: установка и передача другому

## Проще всего — приглашение

Администратор запускает `invite.bat` / `invite.command` в корне проекта и присылает папку с установщиками:
двойной щелчок — и программа скачается, установится и откроется с готовыми настройками.
Подробно — [00-quickstart.md](00-quickstart.md#добавить-ещё-одного-загрузчика).

## Скачать вручную

Всегда свежая сборка: https://github.com/FallAnge1/DuneMedia/releases/tag/uploader-latest

| Система | Файл |
|---|---|
| Windows 10/11 | `VideoArchive-Setup-…exe` (установщик) или `…-windows-portable.exe` (без установки) |
| macOS на Apple M1–M4 | `VideoArchive-…-mac-arm64.dmg` |
| macOS на Intel | `VideoArchive-…-mac-x64.dmg` |

ffmpeg уже внутри — ничего дополнительно ставить не нужно.

> Чтобы собрать новые файлы: GitHub → **Actions → «Сборка загрузчика» → Run workflow**,
> или создайте тег `uploader-v0.1.0` — файлы появятся в Releases.

### Windows

Запустите установщик. Если Windows покажет «Система Windows защитила ваш компьютер» — нажмите
**Подробнее → Выполнить в любом случае** (у программы нет платной цифровой подписи).

### macOS

Откройте `.dmg` и перетащите «VideoArchive» в «Программы». При первом запуске macOS может сказать,
что разработчик не проверен: **правый клик по программе → Открыть → Открыть**
(или «Системные настройки → Конфиденциальность и безопасность → Всё равно открыть»).

## Первый запуск

Мастер настройки проведёт по шагам:

1. **Вход в Telegram** — api_id и api_hash ([02-telegram-api.md](02-telegram-api.md)), телефон, код из Telegram,
   пароль двухэтапной проверки (если включён).
2. **Канал** — username канала. Программа проверит, что вы админ с правом публикации.
3. **Сайт и токен** — адрес сайта и токен ([04-tokens.md](04-tokens.md)).
4. **ИИ-теги** — ключи (необязательно, [05-ai-keys.md](05-ai-keys.md)).
5. **Итог** — покажет лимит размера файла: **2 ГБ**, с Telegram Premium — **4 ГБ**.
   Файлы больше лимита программа не даст загрузить и объяснит почему.

Поменять настройки потом: меню **Настройки → Мастер настройки**.

## Как пользоваться

**Загрузка:** перетащите видео или папки в окно (или «Добавить файлы…»). Программа сразу делает превью,
постер и проверяет дубликаты. Выберите файл — справа можно поменять название, описание, теги
(подсказки из существующих), коллекции и попросить ИИ предложить теги. Выделите несколько файлов
(Ctrl/Shift) — можно разом добавить теги или коллекцию. Нажмите **«Загрузить всё»**.

Если пропал интернет или программу закрыли — при следующем запуске загрузка продолжится.
Видео, которое уже дошло до Telegram, второй раз не отправляется.

**Библиотека:** все видео архива с поиском. Двойной клик — изменить (подпись поста в Telegram
обновится тоже), «Удалить…» — только с сайта или с сайта и из Telegram, «Коллекции…», «Теги…»
(переименовать, слить два тега в один), «Проверить синхронизацию» — найти записи, чьи посты удалили
в канале вручную. Правки, сделанные на сайте, программа сама переносит в подписи постов.

## Передать программу другому загрузчику

1. Администратор канала добавляет человека админом канала ([01-telegram-channel.md](01-telegram-channel.md)).
2. Вы создаёте ему **отдельный** токен: `npm run uploader:create -- "Имя"`.
3. Человек скачивает программу сам (ссылка на Releases) и проходит мастер **своим** Telegram-аккаунтом.

**Не копируйте** свою папку данных программы на чужой компьютер — там ваша сессия Telegram и токен.

## Где программа хранит данные

| Система | Папка |
|---|---|
| Windows | `%APPDATA%\VideoArchive` |
| macOS | `~/Library/Application Support/VideoArchive` |

Там настройки (`config.json`), сессия Telegram, очередь и логи (`logs/app.log`).
Меню **Настройки → Открыть папку с логами** — если что-то пошло не так, приложите `app.log` к вопросу.
