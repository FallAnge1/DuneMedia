## Как всё связано

```
  Программа-загрузчик (ваш компьютер)
    ├─ ffmpeg: превью, постер, кадры для ИИ
    ├─ ИИ (Groq / OpenRouter / Workers AI / Gemini / Ollama): название, описание, теги
    ├─ Telegram (ваш аккаунт) ──► публичный канал: оригинал видео документом, без сжатия
    └─ Сайт (токен загрузчика) ──► Cloudflare Worker
                                     ├─ D1: названия, теги, коллекции, ссылки на посты
                                     └─ R2: превью и постеры

  Зритель ──► сайт: плитка, превью при наведении, поиск ──► клик ──► пост в Telegram ──► скачать
```
