# 8. Закрыть сайт (Cloudflare Access) — без изменения кода

Сейчас сайт открыт по ссылке. Если архив нужно показывать только своим, его можно закрыть входом через
**Cloudflare Access** (Zero Trust). Бесплатно до 50 пользователей. Вход — по коду на почту,
через Google и т. п. Посты в Telegram это не закрывает (канал публичный).

## Что нужно

- **Свой домен** на Cloudflare, подключённый к сайту ([03-cloudflare.md](03-cloudflare.md#свой-домен-по-желанию-но-полезно)).
  Адрес `*.workers.dev` через Access не закрыть — его нужно будет отключить.

## Закрыть сайт для людей

1. Панель Cloudflare → **Zero Trust** (при первом входе выберите название команды и план **Free**).
2. **Access → Applications → Add an application → Self-hosted**.
3. Название — «Видеоархив», **Domain** — ваш домен сайта, например `archive.example.com`.
4. **Policies → Add a policy**: название «Команда», Action **Allow**, Include → **Emails** —
   перечислите почты команды (или **Emails ending in** `@ваша-компания.ru`).
5. Сохраните. Теперь при открытии сайта Cloudflare попросит почту и пришлёт код.
6. Отключите открытый адрес: **Workers & Pages → video-archive → Settings → Domains & Routes** →
   у `workers.dev` нажмите **Disable**.

## Пустить программу-загрузчик

Программа не умеет вводить код с почты, поэтому для неё создаётся **сервисный токен** —
поля для него в программе уже есть.

1. **Zero Trust → Access → Service Auth → Create Service Token**. Название — «Загрузчик», срок — Non-expiring.
2. Скопируйте **Client ID** и **Client Secret** (Secret показывается один раз).
3. В приложении «Видеоархив» (Access → Applications → ваше → **Policies**) добавьте политику:
   название «Загрузчик», Action **Service Auth**, Include → **Service Token** → «Загрузчик».
4. В программе: **Настройки → Мастер настройки** → шаг «Сайт и токен» → заполните
   **Access Client ID** и **Access Client Secret** → «Проверить связь».

Токен загрузчика при этом по-прежнему нужен: Access пускает «к двери», а токен разрешает менять архив.

## Открыть обратно

Zero Trust → Access → Applications → удалите приложение «Видеоархив» и снова включите `workers.dev`, если нужно.
