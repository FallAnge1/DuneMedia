# 1. Канал в Telegram

Видео хранятся в **публичном канале** Telegram. Сайт показывает превью, а за самим файлом отправляет
в пост канала — там видео можно посмотреть и скачать.

## Создать канал

1. В Telegram: **Новый канал** (на телефоне — карандаш → «Создать канал»; на компьютере — меню ☰ → «Создать канал»).
2. Название и описание — любые, например «Видеоархив команды».
3. Тип канала — **Публичный**. Придумайте ссылку (username), например `dune_media_archive`.
   Это латиница, цифры и `_`, 5–32 символа. Username понадобится в программе.
4. **Важно:** в настройках канала выключите **«Запретить копирование»** («Restrict saving content»).
   Иначе зрители не смогут скачивать и пересылать видео.

> Публичный канал виден всем, кто знает ссылку или найдёт его поиском. Если архив не должен быть
> публичным, всё равно оставьте канал публичным (сайту нужны ссылки вида `t.me/канал/123`), но не
> распространяйте ссылку. Закрыть сам сайт можно позже — см. [08-cloudflare-access.md](08-cloudflare-access.md).

## Добавить загрузчиков администраторами

Каждый, кто будет загружать видео, входит в программу **своим** Telegram-аккаунтом и должен быть
администратором канала.

1. Откройте канал → **Управление каналом** (или ⋮ → «Управление») → **Администраторы** → **Добавить администратора**.
2. Найдите человека (сначала он может подписаться на канал).
3. Включите права:
   - **Публикация сообщений** — обязательно;
   - **Редактирование чужих сообщений** — чтобы правки названий и тегов меняли подписи постов, загруженных другими;
   - **Удаление чужих сообщений** — чтобы удалять видео из программы.
4. Остальные права можно выключить. Сохраните.

Программа при настройке сама проверит, есть ли у вас право публикации, и предупредит, если нет права
редактировать или удалять чужие посты.
