# 4. Токены загрузчиков

Сайт открыт для просмотра без входа. **Менять** архив можно только с персональным токеном загрузчика:
в программе-загрузчике или на сайте в режиме редактирования (кнопка с ключом в шапке).

В базе хранится только «отпечаток» (хеш) токена — сам токен показывается один раз при создании.

## Команды

Выполняются в папке `web` (после `npx wrangler login`):

```bash
npm run uploader:create -- "Анна"     # создать токен для Анны
npm run uploader:list                 # кто есть, кто активен
npm run uploader:revoke -- "Анна"     # отозвать все активные токены Анны
npm run uploader:revoke -- --id 3     # отозвать токен по номеру из списка
```

Для локальной разработки добавьте `--local`: `npm run uploader:create -- "Я" --local`.

## Как передать

- Отправьте токен человеку лично (в личные сообщения), не в общий чат.
- Токен вводится в программе на шаге «Сайт и токен загрузчика» (или «Настройки → Мастер настройки»)
  и на сайте — кнопка с ключом.
- Имя из токена подписывается как «Загрузил» у каждого видео.

## Если человек ушёл или токен утёк

`npm run uploader:revoke -- "Имя"` — токен перестаёт работать сразу: в программе и на сайте.
Уже загруженные им видео остаются. Новый токен — `uploader:create`.
